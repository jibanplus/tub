# TUB Creator Website

A dark futuristic Web3 creator portfolio recreation with content admin.

## Run
Open `index.html` in a browser. For best results, use a static local server or deploy the folder to Netlify.

## Admin
Open `admin.html`. Demo credentials: `admin` / `matrix2026`.

Admin includes creator profile, section copy, social URLs, FAQ and Gallery/Uploads. Uploads are resized and stored in this browser's localStorage; they are not shared across devices or visitors. To make admin updates global on a deployed site, connect a hosted CMS/database and secure authentication.

## Notes
Gallery starter visuals load from Unsplash. Uploaded images override/add gallery cards in local browser storage.
